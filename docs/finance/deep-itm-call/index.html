Deep ITM Call as a Futures Alternative

從線性多頭部位到選擇權的保護結構 · 2026.11.24

01. Motivation ｜動機

當指數期貨漲停鎖死，想增加多頭曝險卻無法成交時，是否可以改買 Call？深度價內（Deep In-the-Money, ITM）Call 的 Delta（標的現貨價格每變動一點時，Call 價格的局部變化率）通常接近 1，在標的價格小幅變動時，單位契約的損益接近線性期貨，但它同時具有下跌保護，這項保護並非免費。

本文件從熟悉的期貨損益出發，建立 Call 的價格與風險結構，再回到履約價選擇及實際市場報價。

範圍：以歐式、同標的、同到期日及同結算基準的合約為主。除另有說明，忽略利率、交易稅費及契約乘數差異。以遠期代表線性部位，期貨在每日結算、保證金等制度上仍有差異。

02. Special Case: K = F ｜從期貨出發

本節要建立一個核心觀念：Long Call 可以拆解成 Long Forward 加上 Long Put，也就是線性多頭部位加上下跌保護。先從履約價等於公允遠期價格的特例出發，透過到期損益驗證這個關係。先定義本文件的基本符號：

符號英文名稱定義
\(S\)Spot Price當前標的現貨價格
\(S_T\)Settlement Price at Expiration到期時的標的結算價格
\(T\)Time to Expiration剩餘到期時間（年）
\(F\)Forward Price當前同到期日的公允遠期價格
\(K\)Strike Price選擇權履約價
\(C, P\)Call Premium, Put PremiumCall、Put 的當前權利金
\(\Pi(S_T)\)Profit and Loss (P&L)到期損益，以結算價格為自變數

令 \(F=K=40{,}000\)，\(P=400\)。以公允價格建立的遠期合約初始價值為零，另支付 400 點買入 Put。以下忽略利率及交易成本，價格及損益均以點數表示。

Long Forward

到期損益為結算價格減去約定買入價格。

\[\begin{aligned}\Pi_{\mathrm{forward}}(S_T)&=S_T-F\\&=S_T-40{,}000\end{aligned}\]

Long Put

Put 在結算價格低於履約價時提供保護，扣除初始保費才是損益。

\[\begin{aligned}\Pi_{\mathrm{put}}(S_T)&=\max(K-S_T,0)-P\\&=\max(40{,}000-S_T,0)-400\end{aligned}\]

Combined Position

將兩個部位的損益相加，利用此處 \(F=K\) 的條件：

\[\begin{aligned}\Pi_{\mathrm{total}}(S_T)&=\Pi_{\mathrm{forward}}(S_T)+\Pi_{\mathrm{put}}(S_T)\\&=S_T-K+\max(K-S_T,0)-P\\&=\max(S_T-K,0)-P\\&=\max(S_T-40{,}000,0)-400\end{aligned}\]

當 \(S_T\ge K\) 時，Put 不理賠，組合保留線性上漲損益。當 \(S_T<K\) 時，Put 理賠正好抵銷線性部位的下跌損失，組合只損失保費。另一方面，Long Call 的到期損益為：

\[\Pi_{\mathrm{call}}(S_T)=\max(S_T-K,0)-C\]

比較兩者可知，在無套利且忽略折現的條件下，當 \(K=F\) 時，\(C=P\)。因此買入 40000C 並支付 400 點，與上述組合具有相同的到期損益。

\[\text{Long Call}=\text{Long Forward}+\text{Long Put}\]

這就是將 Call 理解為線性多頭部位加上下跌保護的理由。

合約初始價值為零不代表沒有方向性曝險。保證金是履約擔保，而非權利金。

03. Generalization ｜任意履約價

若 F 不變，而約定買入價格 K 不同，合約價值就必須補償兩者的差距。以 F = 40,279 為例：

負值代表接手這份不利的線性合約時，應收到補償。降低 K 1,000 點，會多支付 1,000 點合約價值，但未來約定價格少 1,000 點。忽略折現，兩者抵銷。令 \(V_{\mathrm{forward}}\) 表示這份遠期合約的當前價值。

\[V_{\mathrm{forward}}\approx F-K\]

因此 Forward Value 是既有遠期合約的當前價值，而非預期利潤。若結算在 F，這筆價值正好由線性部位的結算價值抵銷。Call 的內含價值則是 \(\max(S-K,0)\)，以現貨 S 為基準，不可與 Forward Value 混用。

04. Put-Call Parity ｜統一數學結構

將任意履約價的線性部位加上同履約價 Put，仍可得到 Call 的到期價值：

\[\max(S_T-K,0)=(S_T-K)+\max(K-S_T,0)\]

相同的到期現金流，在無套利條件下應具有相同的當前價值。令 \(r\) 為連續複利的無風險年利率，於是得到 Put-Call Parity：

\[C-P=e^{-rT}(F-K)\]

當剩餘到期時間 \(T\) 很短，且 \(\lvert rT\rvert\ll 1\) 時，可近似取 \(e^{-rT}\approx 1\)，因此：

\[\begin{aligned}C&\approx(F-K)+P\\F&\approx K+C-P\end{aligned}\]

在上述忽略折現的近似條件下，Call 的到期損益可以重寫為：

\[\begin{aligned}\Pi_{\mathrm{call}}(S_T)&=\max(S_T-K,0)-C\\&\approx(S_T-F)+\max(K-S_T,0)-P\end{aligned}\]

第一項是純線性曝險，第二項是保險理賠，第三項是保險費。這個近似分解對任意 K 適用，不限於 ITM。

當 Call 越深度價內，對應 Put 的價格及 Delta 通常越接近零，Call Delta 越接近 1，損益越接近遠期。當 \(K>F\) 時，Forward Value 為負值，因此 Put 權利金高於 Call 權利金。此時 Call 的價格由正的 Put 權利金與負的 Forward Value 相加而成。

05. Strike Selection ｜履約價取捨

履約價可以理解為保護門檻。降低 K，就像提高自行承擔的下跌幅度：保費下降，但需要投入更多本金，且保護較晚生效。

單口最大虧損增加減少
到期損益兩平價降低提高
同資金可買口數減少增加

令 \(S_{\mathrm{BE}}\) 表示忽略利率與交易成本時的到期損益兩平價。

\[S_{\mathrm{BE}}=K+C\approx F+P\]

權利金較高不等於保險成本較高。降低 K 雖提高本金需求，卻降低獲利門檻。以下 39K 報價為假設，40K 來自本次觀察，F 取 40,279。

預期上漲幅度越大，較高履約價的方案可能因口數增加而取得更高報酬，但必須漲得足以跨越方案間的損益交叉點，而非只要看對方向即可。這是相近本金的比較，不是相同 Delta 的比較。高履約價也提高歸零風險。

跨越 ATM 是否改變規則？

到期前，標準平滑定價模型中，Call 價格、Put 價格與 Delta 隨 K 連續變化，但並非線性。跨越現貨 S 時，Call 內含價值變成零，跨越遠期 F 時，Forward Value 變號。這兩個分界不必相同。到期時，Call 損益在 K 處有折點。

Price Discovery

期貨價格受到漲跌停限制時，選擇權可能提供額外價格訊號。應使用同到期、同結算基準且同步的 Bid / Ask。合成多頭的可成交價格約為 \(K+C_{\mathrm{ask}}-P_{\mathrm{bid}}\)，合成空頭則約為 \(K+C_{\mathrm{bid}}-P_{\mathrm{ask}}\)（下標 ask、bid 分別代表賣方報價與買方報價）。最後成交價不一定可成交，選擇權也可能受到價格限制或缺乏流動性。

本次資料並未顯示隱含遠期高於期貨漲停價，尚須確認報價同步性及期貨到期日是否一致。隱含遠期不是實際機率下的明日結算預測。若持有至結算，應比較實際結算價格而非盤中高點。

用 Call 取代期貨：比較 K + C 與自己對結算價分布的判斷。研究價格發現：觀察 K + C − P。兩者用途不同。

07. Dive Deeper ｜延伸探索

以下是本次發現但不要求立即掌握的延伸入口。

Put-Call Parity & Greeks

在無股息、忽略利率的簡化模型下，對價格關係取偏微分，可得到 以下關係（下標 C、P 分別代表 Call、Put，\(\Delta\) 為價格對現貨價格的一階偏導，\(\Gamma\) 為二階偏導，Vega 為對波動率的偏導）：

\[\begin{aligned}\Delta_C&=1+\Delta_P\\\Gamma_C&=\Gamma_P\\\mathrm{Vega}_C&=\mathrm{Vega}_P\end{aligned}\]

可進一步研究線性部位與保護如何分擔風險曝險。

Option Elasticity (Omega)

\(\Omega=\frac{\Delta_C S}{C}\)，其中 \(\Omega\) 為有效槓桿（Elasticity），衡量標的價格變動 1% 時 Call 價格的局部百分比變化。可用來比較同資金下的即時方向性曝險，而非僅比較口數。
