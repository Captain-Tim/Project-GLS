# Writing Style Guide

- 使用繁體中文與台灣慣用術語。
- 避免中文分號，優先使用逗號或句號。
- 重要專業術語保留英文名稱。
- 優先建立直覺，再引入數學定義、公式與推導。
- 圖表服務於理解，而非裝飾。
- 明確區分 Core Knowledge 與 Dive Deeper。
- 精簡文字但不犧牲必要的解釋、假設及適用條件。

視覺風格暫不設強制規範，依實際文件閱讀經驗逐步改善。

## Mathematics

- 所有數學符號須在首次使用前或首次使用時定義，不重複定義已介紹的符號。
- 使用 LaTeX 渲染正式數學公式，包含變數斜體、上下標與多行等號對齊。
- 原則上先呈現一般式，再代入具體數值。
- 保留有助於理解的關鍵推導步驟，清楚標示近似與適用條件。
- 獨立數學公式直接融入正文，以留白區隔，不使用 Callout 背景、邊框或裝飾性側線。
