# Project-GLS

General Learning System — a personal knowledge repository for AI-assisted learning.

**Less is More.**  
**Automate the mechanics. Own the understanding.**

## Learning workflow

1. Explore — 探索與建立理解。
2. Reconstruct — 不依賴原始資料，獨立重建知識。
3. Validate — AI 逐一提出問題與反例，學習者自行修正。
4. Consolidate — 將已驗證的理解整理成有脈絡的知識文件。

依主題的重要性調整深度，不要求每次都完整執行所有步驟。從實際使用中改善系統。
