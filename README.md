# Project-GLS

General Learning System — a personal knowledge repository for AI-assisted learning.

**Less is More.**  
**Automate the mechanics. Own the understanding.**

## Learning workflow

1. Explore — 探索與建立理解。
2. Reconstruct — 不依賴原始資料，獨立重建知識。
3. Validate — AI 逐一提出問題與反例，學習者自行修正。
4. Consolidate — 將已驗證的理解整理成有脈絡的知識文件。

依主題的重要性調整深度，不要求每次都完整執行所有步驟。從實際使用中改善系統。

### Spaced Repetition

Consolidate 完成後，對值得長期保留的知識安排 Day 1、Day 7、Day 30 間隔複習，以文件完成日為 Day 0。

- 每次約 5–10 分鐘，以 Active Recall 為主，不預先重讀文件。
- AI 依已驗證的核心知識逐題提問，等待學習者回答後才驗證及繼續。
- 僅在發現理解或記憶缺漏時回顧文件，不要求重新輸出整份知識。
- 依實際複習結果調整後續間隔。1、7、30 天為目前的實驗性預設，而非強制規範。
- 經學習者同意後，由 AI 設定複習提醒，附上對應知識文件的連結。
